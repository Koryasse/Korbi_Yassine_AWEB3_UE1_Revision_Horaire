## Procédure de création/importation de la base de données
1. Se rendre sur localhost/phpmyadmin
2. Cliquer sur le bouton "Importer"
3. Séléctionner le fichier se trouvant dans /sql et importer 

## URL DES API
http://localhost/CFPT3/AWEB%20SOTO/GestionHoraire2/GestionHoraire/api/?resource=cours
